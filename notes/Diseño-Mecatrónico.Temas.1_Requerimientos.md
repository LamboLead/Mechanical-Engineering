## PDS: Product Design Specification

Es una metodología que busca especificar los requerimientos necesarios para el diseño del producto. Consiste en la explicación de los siguientes rubros:

| Rubro | Explicación |
|---|---|
| Categoría | Categoría a la que pertenece el requerimiento. |
| Necesidad | Explicación de la necesidad a suplir con el requerimiento. |
| Requerimiento | Descripción o especificación de las necesidades o demandas que tiene el cliente respecto a la necesidad planteada. |
| Variable | ¿Con qué variable se podría medir el cumplimiento de este requerimiento? |
| Unidades | Unidades asociadas a la medición de esta variable. |
| Valor | Valor con el cual se considera que este requerimiento ha sido cumplido. |
| Prioridad | ¿Qué tan importante es el cumplimiento de este requerimiento? |
| Fuente | ¿Quién establece el requerimiento? (cliente, regulación, mercado, etc) |
| Fecha | ¿En qué fecha fue cumplido este requerimiento? |
| Verificación | ¿Cómo se verificaría el cumplimiento de este requerimiento? |

> Es necesario compartir el PDS con el cliente para que éste esté enterado de los requerimientos del proyecto.
