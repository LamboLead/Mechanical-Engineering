## Objectives

This section intends to explan how to create and run a simulation, and explain concepts about phisically-based object oriented simulations.

---

**Why to simulate?** A circuit is simulated because there are many details that the designer may not know that the simulation system takes into account.

**Object-oriented, physical system simulation:** These are simulation systems that take each object as a physical object with their different physical properties and laws.
