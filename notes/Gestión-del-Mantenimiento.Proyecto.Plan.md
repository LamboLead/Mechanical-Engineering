Este es el plan a seguir para completar de forma satisfactoria el proyecto.

## Introducción
- [ ] Aprender cómo funciona Yéminus
- [ ] Definir objetivos del proyecto
- [ ] A partir de los objetivos, definir tareas a realvizar y asignarlas a los compañeros.
- [ ] Para cada proceso realizado, definir una plantilla de trabajo (ejemplo: Plantilla para realizar Análisis Causa Raíz, 5 Por Qué, Diagrama de Ishikawa)

## Sobre la maquinaria

### Análisis del riesgo
- [ ] Realizar un análisis de criticidad de toda la maquinaria de la empresa para asignar una calificación de criticidad basada en su riesgo potencial (se puede realizar de forma simple o compleja)
- [ ] Elegir la maquinaria más crítica a analizar e implementar el proyecto en base a esta.

### Recolacción de información
- [ ] Recolectar y escanear los manuales de usuario de la maquinaria.
- [ ] Realizar un análisis funcional a la maquinaria.
- [ ] Recolectar recomendaciones de uso y mantenimiento o definirlas a partir de maquinaria similar.
- [ ] Ingresar toda esta información en el programa Yéminus. 

### Caracterización de las fallas
Para cada una de las fallas encontradas _desde que el proyecto inició_:
- [ ] Realizar un Análisis de Causa Raíz (implementar 5x por qué, diagrama de Ishikawa)

Para cada máquina elegida en [el punto anterior](#criticidad-de-la-maquinaria):
- [ ] Realizar un FMEA, caracterizando cada falla potencial y falla ocurrida.

## Gestión del Mantenimiento

### Plan de mantenimiento preventivo
- [ ] Plantear un procedimiento de mantenimiento preventivo en base a los resultados del FMEA (gráfico de procedimiento).
- [ ] Ejecutar el plan en una maquinaria ficticia, de tal forma que sirva como plantilla. Esto incluye creación de órdenes de trabajo, creación de bitácora de mantenimiento, manejo de inventarios.

# Ideas

- Para cada uno de los procesos implementados, crear una plantilla y una guía con pasos a seguir de tal forma que el jefe de mantenimiento pueda realizarlos en el futuro. Dichos procesos son:
  - Creación y llenado de órdenes de trabajo.
  - Análisis de criticidad (no obligatorio).
  - Análisis funcional de una máquina (no obligatorio).
  - Creación de planes de mantenimiento preventivo.
  - Creación de FMEAs.
  - Desarrollo de Análisis Causa-Raíz.
- Toda información planteada debe ser ingresada en el programa en forma de campo en base de datos o en forma de documento.
